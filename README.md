## 📋 Descripción

App Android desarrollada en Kotlin con Jetpack Compose para el control de asistencia de docentes. Se conecta con [asistencia-api](https://github.com/garrawil-cyber/asistencia-api) para sincronizar los datos.

## ✨ Características

- 📱 Interfaz moderna con Material Design 3
- 🔄 Sincronización en tiempo real
- 📊 Reportes de asistencia
- 👥 Gestión de docentes
- 📅 Historial por fecha
- 🔔 Notificaciones push

## 🛠 Stack Tecnológico

- **Kotlin** — Lenguaje principal
- **Jetpack Compose** — UI moderna
- **Retrofit** — Cliente HTTP
- **ViewModel + LiveData** — Arquitectura MVVM
- **Room** — Base de datos local
